TF-IDF Vector Space Algorithm Blueprint

All mathematical formulations and Python implementation specifications kept here.

1. Mathematical Formulas

How textual words are converted into mathematical vectors:

Term Frequency (TF): TF(t, d) = 1 + ln(count(t, d))   [sublinear scaling] Measures how frequently term t appears in film description d.
Inverse Document Frequency (IDF): IDF(t, D) = ln((1 + |D|) / (1 + DF(t))) + 1 Downweights generic words that appear in many movies.
Composite TF-IDF Weight: w(t, d) = TF(t, d) × IDF(t, D) High value only if term is frequent in this film but rare overall.
Cosine Similarity (Angular Distance): cos(θ) = (A · B) / (||A|| × ||B||) = ∑ (w_A,t × w_B,t) Calculates similarity angle between two normalized film vectors.

2. Python Architecture (recommender.py)

Core pipeline implemented with scikit-learn and NumPy:

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 1. Initialize Vectorizer with Unigrams + Bigrams
vectorizer = TfidfVectorizer(
    stop_words="english",
    max_features=6000,
    ngram_range=(1, 2),
    sublinear_tf=True
)

# 2. Fit and Transform Metadata Soup into Sparse Matrix
tfidf_matrix = vectorizer.fit_transform(df["soup"])
# Shape: (4813, 6000)

# 3. Compute Pairwise Cosine Similarity
cosine_sim = cosine_similarity(tfidf_matrix, tfidf_matrix)

# 4. Top-K Recommendations for Target Movie
scores = list(enumerate(cosine_sim[source_idx]))
recommendations = sorted(scores, key=lambda x: x[1], reverse=True)[1:top_n+1]
