How the TF-IDF Vector Space Model Operates in Python

01

Metadata Soup Synthesis

Combines weighted tokens: Director (×3), Genres (×4), Cast (×2), Keywords (×2), and Plot into a single bag-of-words document.

soup = (dir*3) + (gen*4) + cast + plot
02

Sublinear TF-IDF Vectorizer

Extracts unigram & bigram features. Applies sublinear term scaling $\text{TF} = 1 + \ln(\text{count})$ and downweights ubiquitous corpus terms via inverse document frequency.

IDF(t) = ln((1+N)/(1+DF)) + 1
03

L2 Hypersphere Normalization

Normalizes each 5,000-dimensional vector onto the unit Euclidean sphere ($\|\mathbf{v}\|_2 = 1$). Eliminates film synopsis length bias.

v̂ = v / ||v||₂ (in ℝ⁵⁰⁰⁰)
04

Cosine Similarity Kernel

Computes angular inner product $\cos(\theta) = \mathbf{A} \cdot \mathbf{B} = \sum (w_{A,i} \times w_{B,i})$. Yields exact affinity scores in $[0, 1]$ across all 247 films.

cos(θ) = u · v = ∑ (TF_A × TF_B × IDF²)

TF-IDF Vector Space Recommendation Architecture

Detailed mathematical derivation, linear algebra formulation, and Python implementation.

1. Mathematical Formulation

The algorithm maps unstructured textual movie metadata into a structured Euclidean vector space:

Sublinear Term Frequency (TF): \text{TF}(t, d) = \begin{cases} 1 + \ln(\text{count}(t, d)) & \text{if count} > 0 \\ 0 & \text{otherwise} \end{cases} Dampens the influence of repeatedly occurring terms.
Smooth Inverse Document Frequency (IDF): \text{IDF}(t, D) = \ln\left(\frac{1 + |D|}{1 + \text{DF}(t)}\right) + 1 Penalizes generic words and heavily rewards distinctive narrative keywords.
L2 Vector Normalization: \vec{v}_d = \frac{\mathbf{w}_d}{\|\mathbf{w}_d\|_2} = \frac{\mathbf{w}_d}{\sqrt{\sum_{i=1}^{5000} w_{d,i}^2}} Projects all film vectors onto the unit hypersphere in $\mathbb{R}^{5000}$.
Cosine Similarity Metric: \cos(\theta) = \vec{v}_A \cdot \vec{v}_B = \sum_{i=1}^{5000} v_{A,i} \times v_{B,i} \in [0, 1] Computes the angular distance between two movies.

2. Python Architecture (recommender.py)

Core vectorization pipeline using scikit-learn and NumPy:

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 1. Initialize Vectorizer with Unigram + Bigram Range
self.vectorizer = TfidfVectorizer(
    stop_words="english",
    max_features=5000,
    ngram_range=(1, 2),
    sublinear_tf=True
)

# 2. Fit and Transform Metadata Soup into Sparse CSR Matrix
self.tfidf_matrix = self.vectorizer.fit_transform(self.df["soup"])
# Shape: (247, 5000)

# 3. Precompute Full Pairwise Cosine Similarity Matrix
self.cosine_sim = cosine_similarity(self.tfidf_matrix, self.tfidf_matrix)

# 4. Top-K Ranking for Target Movie
sim_scores = sorted(
    list(enumerate(self.cosine_sim[source_idx])),
    key=lambda x: x[1], 
    reverse=True
)[1:top_n+1]
